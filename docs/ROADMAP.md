# Roadmap

## Now: useful prototype
- [x] Mobile discovery screen with sample, low-barrier activities
- [x] Minimal API and deterministic guide endpoint
- [x] Shared types and privacy/safety principles
- [ ] Add tests, accessibility audit, and contributor onboarding

## Next: community-grounded discovery
- Co-design with libraries, local groups, and people facing access barriers.
- Create a reviewed opportunity format including cost, location, accessibility, age suitability, and organizer contact.
- Add reporting and correction workflows before expanding listings.
- Test the experience with volunteers; publish what helped and what did not.

## Later: careful personalization
- Offer optional preferences stored on-device first.
- Explain why recommendations appear and let people reset preferences.
- Evaluate usefulness and fairness across different communities before launch.
- Consider an external AI only for a clearly defined task, with consent, safeguards, and an equivalent non-AI path.

## Impact measures to co-design

Start with participant-defined measures: Did someone find an activity they could actually access? Did it lead to a meaningful learning or community experience? What barriers remained? Avoid treating downloads, time spent, or data volume as impact.
